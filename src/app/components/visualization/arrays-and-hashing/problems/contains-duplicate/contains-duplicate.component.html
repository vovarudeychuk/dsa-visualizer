Contains Duplicate

Problem Description

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

Examples

Input: nums = [1,2,3,1]
Output: true

Input: nums = [1,2,3,4]
Output: false

Solution Explanation

This problem can be solved efficiently using a HashSet. Here's how it works:

Time Complexity: O(n) - We only need to traverse the array once

Space Complexity: O(n) - In the worst case, we might need to store all elements in the set

How it works:

  1. Create an empty HashSet to store numbers we've seen
  2. Iterate through each number in the array
  3. For each number, check if we've seen it before (is it in the set?)
  4. If we have seen it, we found a duplicate - return true
  5. If we haven't seen it, add it to our set
  6. If we complete the loop without finding duplicates, return false
